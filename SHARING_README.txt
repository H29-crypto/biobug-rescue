BioBug Rescue - source package

Source, tests, documentation and frontend anatomical assets are included.
Installed dependencies, caches, Git history and credentials are excluded.
The 1.9 GB raw MaleCNS dataset is not included in this smaller package.

Frontend: npm ci, then npm run dev -- --configLoader bundle.
Backend: follow backend/README.md, including python -m connectome.download.
Optional AI Commander uses the recipient's own backend-only API key.
See README.md and docs/ for the project architecture and scientific scope.
